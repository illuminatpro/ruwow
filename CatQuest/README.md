# CatQuest — «Котейный модуль»: озвучка квестов, книг и лора мест для WoW Forever (русский клиент)

Квесты читает голос квестодателя, сдачу — тот, кому сдаёшь, книги и историю мест — рассказчик.
Голоса подобраны под расу и пол NPC по репликам актёров из самой игры. Ничего настраивать не нужно:
поставил аддон и пак — заработало.

Версия **0.3.1** (30.09.2026): аддон 0.3.1 (хотфикс: лор на такси), паки озвучки 0.3.0. Также на CurseForge: CatQuest, CatQuest Voices, CatQuest Books. Клиент: WoW Forever, интерфейс 16001, ruRU.

## Из чего состоит
| Часть | Что это | Размер |
|---|---|---|
| `CatQuest` | сам аддон | < 5 МБ |
| `CatQuest_Voices` | пак озвучки квестов: 1979 квестов (1978 описаний, 1687 сдач), 4814 файлов | 484 МБ |
| `CatQuest_Books` | пак книг, записок, табличек и лора мест: 2561 текст, 2631 файл | 375 МБ (по желанию) |
| компаньон | отдельная программа для живой озвучки того, чего нет в паках | по желанию |

## Установка
1. Распаковать `CatQuest` и `CatQuest_Voices` (и `CatQuest_Books`, если хочется книги и лор) в
   `World of Warcraft\_classic_beta_\Interface\AddOns\`. Должно получиться `AddOns\CatQuest\CatQuest.toc` — без лишней папки
   между ними. **Mac**: Archive Utility распаковывает архив в папку с именем архива (`CatQuest-0.2.0-beta/CatQuest/…`) —
   в `AddOns` нужно перетащить папки *изнутри* неё; при замене старой версии выбирать «Заменить», а не «Оставить обе»
   (иначе появится `CatQuest 2`). Признак ошибки — красное окно «AddOn [CatQuest] failure to load: missing».
2. Запустить игру (если игра была открыта — **полный перезапуск**, иначе клиент не увидит новые звуки).
3. Громкость озвучки — ползунок **«Диалоги»** в настройках звука игры.
4. Проверка: `/cq selftest` — должно быть «пак квестов загружен» и «пак книг/лора загружен».

## Что умеет аддон

### Квесты
- **Взятие квеста** — описание читается сразу голосом квестодателя; можно уйти от NPC, озвучка продолжится.
- **Сдача** — текст награды читает тот NPC, которому сдаёшь (1656 сдач в паке).
- **Задание и название** читаются после описания (отключается).
- Взял несколько квестов подряд — читаются **по очереди** («ещё N» на панели), дубли не ставятся.
- Голоса: 22 расовых голоса (муж/жен для людей, орков, дворфов, ночных эльфов, нежити, тауренов, троллей,
  гномов, гоблинов, эльфов крови, Skyborne), именные голоса для Кэрна, Магаты, Фэндрала, Газлоу, Холланда.
  Квесты без известного квестодателя читает рассказчик.
- Если в паке нет квеста (новый или кастомный квест Forever) — молчим, либо читает компаньон (см. ниже).
- **Приветствие NPC** не перебивается: аддон знает длину приветственной реплики по облику NPC (852 облика)
  и начинает читать после неё.

### Книги, записки, таблички
- Открыл книгу, письмо или табличку — текст читает рассказчик (пак `CatQuest_Books`, 1631 страница).
- Если такого текста в паке нет — озвучки нет (или компаньон).

### Лор мест
- Вошёл в локацию или подзону (938 мест в 47 зонах: вся ванилла, столицы, Хиджал, Лунная поляна) —
  появляется **свиток** с названием места (перетаскивается). Тап — рассказчик читает историю в говорящей голове с субтитрами,
  через общую очередь: квест, взятый во время рассказа, встанет следом.
- Тексты написаны по классической эпохе с проверкой по вики и русским данным клиента.
- `/cq lore` — список лора текущей зоны, `/cq lore here` — прочитать ближайшее место, `/cq lore reset` — забыть посещённые места.
- Настройки → «Лор мест» → «Читать при входе в локацию»: рассказ начинается сам при первом входе в зону/подзону,
  услышанное помнится на всех персонажах и повторно не играет (в бою — ждёт конца боя).

### Сюжет зоны — временно выключен
Истории зон по главам («где я в сюжете зоны, что дальше») в этой бете отключены: порядок глав и интерфейс переделываются.
Вернутся в одной из следующих версий.

### Плеер
- **Говорящая голова** внизу экрана: круглый портрет NPC (по облику, 935 NPC),
  имя, название квеста, полоса с временем «0:12 / 0:31», «ещё N» (наведение — что в очереди, клик — окно «Очередь»),
  кнопки «дальше» и «×» (стоп и очистить), **субтитры** по предложениям на подложке (тайминги из пака).
  Наведение — подсказка с полным именем, названием, источником и голосом. Плавно появляется и исчезает, перетаскивается,
  есть масштаб, «закрепить» и **компактный режим** (только портрет и субтитры, остальное — при наведении).
- Окно `/cq`: вкладки «Мои квесты» (квесты без озвучки — серым), «Очередь» (клик — прочитать сейчас, правый клик — убрать)
  и «История».
- Кнопка **«Читать»** в журнале квестов — переслушать любой квест.
- Горячие клавиши: «Меню → Назначение клавиш → AddOns → CatQuest» (прочитать/стоп, следующий в очереди, окно).

## Команды
| Команда | Что делает |
|---|---|
| `/cq` | повторить последний текст / остановить |
| `/cq stop` | остановить и очистить очередь |
| `/cq q` | окно «Мои квесты» — клик озвучивает; без озвучки — серым |
| `/cq h` | история озвученного (в том же окне — вкладка «Очередь») |
| `/cq log` | прочитать выбранный в журнале квест |
| `/cq lore` / `/cq lore here` / `/cq lore reset` | лор зоны / прочитать ближайшее место / забыть посещённые |
| `/cq pack <id>` | проиграть квест из пака по номеру |
| `/cq options` | настройки |
| `/cq selftest` | самопроверка: паки, базы, API, пробный звук |
| `/cq mismatches` | квесты, где голос из пака не совпал с расой/полом NPC перед тобой |
| `/cq export` | **отчёт для автора**: квесты без озвучки, неподходящие голоса, ошибки — скопировать и прислать |
| `/cq errors` | ошибки аддона за сессию (аддон их не показывает, а копит) |
| `/cq report` | одна строка для баг-репорта: что играло последним |
| `/cq companion` | как поставить компаньон |
| `/cq diag`, `/cq npc` | техническая информация |

## Настройки (`/cq options`)
Сгруппированы по разделам: **Что читать** (взятие, сдача, книги; отдельно — «ещё не готово», приветствия, диалоги — они есть
только у компаньона и по умолчанию выключены; название и задача), **Как читать** (очередь, после «Принять», ждать приветствие NPC,
дослушивать после закрытия окна, «не обрывать при сворачивании игры», «играть в основной канал» — если «Диалоги» у клиента не звучат),
**Голова и субтитры** (голова, субтитры, компактный режим, закрепить, масштаб), **Лор мест**, **Для автора** (отчёт, копить тексты), **Компаньон**, **Встроенный TTS**.
При первом запуске аддон здоровается в чате и говорит, где настройки; после обновления — одной строкой сообщает версию.

Настройки в бете Forever **не сохраняются между запусками** — это баг клиента (у всех аддонов), не CatQuest.

## Компаньон (по желанию)
Отдельная программа озвучивает вживую всё, чего нет в паках: новые и кастомные квесты, диалоги, «ещё не готово».
Аддон передаёт текст через полоску пикселей в углу экрана, компаньон только читает экран и ничего в игре не нажимает.
Голоса — Silero (офлайн, без интернета) или Microsoft (облако). Рядом ставится маячок `CatQuest_Bridge` —
с ним аддон сам включает передачу текста.

```
tools\companion_dev.bat          # запуск (нужен Python; .exe — в планах)
```

## Известные проблемы беты
- **Ударения кое-где ещё промахиваются.** В 0.2.0 словарь имён и омографов вычищен системно (снимок разметки, проверка
  словаря), но модель синтеза изредка игнорирует даже верную разметку, а ошибки измерения детектора возможны. Найденные на слух
  случаи присылайте — чиним пачками через перегенерацию.
- **Кастомные квесты Forever**: описания озвучены голосами NPC (данные с Wowhead Forever), сдачи — частично временным переводом
  с английского (Wowhead русского текста сдач пока не отдаёт); настоящий текст подтянется из отчётов игроков (`/cq export`).
- **Реплики «ещё не готово», приветствия и болтовня NPC** в паке не озвучены — их читает только компаньон.
- **Настройки не сохраняются между запусками** — баг клиента беты Forever (у всех аддонов).
- **Голова и субтитры идут, а звука нет** — озвучка играет в канал «Диалоги»: проверьте, что он включён и ползунок не на нуле
  (настройки звука игры). С 0.1.2 аддон при выключенных «Диалогах» сам переключается в основной канал и пишет об этом в чат;
  `/cq selftest` проверяет каналы и громкость, `/cq report` показывает их в строке (`ch=`, `snd=`, `dv=`).
- **Новые файлы пака клиент видит только после полного перезапуска игры**, `/reload` не хватает.
- Голоса собраны нейросетью по репликам актёров игры: интонация иногда ровнее живой, тембр может чуть отличаться от оригинала.

## Как помочь паку: `/cq export`
Пока вы играете, аддон тихо копит короткий отчёт — то, что нужно, чтобы озвучить недостающее и поправить неподходящее:
- квесты и книги **без озвучки** — кто их выдаёт или принимает (номер NPC, облик, раса, пол) и текст;
- квесты, которые читает рассказчик, хотя NPC известен, — ему можно дать свой голос;
- квесты, где **голос не подходит** персонажу;
- квесты, где **текст на экране не совпал** с текстом, по которому собран файл (пак читает старую редакцию) — с настоящим текстом;
- ошибки аддона.

`/cq export` открывает окно с отчётом: **Ctrl+C** и вставить в Discord или Telegram (длинный отчёт мессенджер
сам превратит в файл). Ничего не отправляется само; имя персонажа в отчёт не попадает (заменяется на `$N`).
После отправки — кнопка «Очистить отчёт», чтобы в следующий попало только новое. Выключается в настройках
(«Копить отчёт для автора»). Пока бета не сохраняет данные аддонов между запусками, отчёт — за текущую сессию:
лучше отправлять его перед выходом из игры.

## Как сообщить о конкретной проблеме
1. Сразу после проблемного места — `/cq report` и скопировать строку из чата.
2. Если голос не тот — `/cq mismatches`; если что-то сломалось — `/cq errors`.
3. Прислать вместе с названием квеста.

  файлы и звук честно, «не обрывать при сворачивании», «основной канал»; автопроверка `coverage` (кэш → база → пак) и чек-лист релиза.

  иконки вместо кнопок, плавное появление, компактный режим; вкладка «Очередь» и серые квесты без озвучки в окне `/cq`;
  настройки по разделам; приветствие при первом запуске.

  озвучка не обрывается при сворачивании; Кага Дикое Копыто и ещё два NPC Forever — своими голосами (`tools/data/npc_manual.json`).

2. Лор для новых зон Forever (Гилнеас, Лесоречье, Шен'дралас, Акульи воды, острова) — после сбора квестов из игры.
3. Сюжеты зон заново: пролог стартовой долины первой главой, порядок глав по уровням, только квесты твоей расы и класса

4. Компаньон в один `.exe` (Silero офлайн по умолчанию, голос по полу NPC).
5. Больше именных голосов (персонажи с собственными репликами в клиенте) и по нескольку актёров на расу.

**Дальние идеи**
- Ползунок скорости чтения. Клиент WoW не умеет менять скорость звука (`PlaySoundFile` без параметров темпа),
  так что это только заранее ускоренные копии пака (+300–600 МБ) или плавная скорость через компаньон. Отложено.

## Для авторов пака
Инструменты — в `tools/`: сбор текстов и NPC из игры (`/cq mine`, `build_npcdata.py`), референсы голосов
(`build_voice_references.py`), генератор (`build_pack.py`, режимы `detail`/`complete`/`book`), лор
(`build_lore_skeleton.py`, `merge_lore.py`, `export_lore.py`), сюжеты (`build_storylines.py`), приветствия (`build_greet.py`),
контроль (`qa_all.py`, `qa_issues.py`), релиз (`build_release.py`), словарь ударений `data/stress_dict.txt`.
Подробности и история решений — в `docs/`.

Голоса сгенерированы моделью F5-TTS (русское дообучение, CC BY-NC) по репликам NPC из клиента игры.
Пак — фанатский, некоммерческий; тексты и голоса принадлежат Blizzard Entertainment.
